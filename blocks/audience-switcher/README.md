# audience-switcher

Custom **form** block. Purpose: Radio toggle that switches page content between audiences (domestic / international, individuals / organisations).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: single cell label (e.g. 'Showing information for'). Rows 2+: cell 1 = option label (e.g. 'Domestic students'), optional cell 2 = audience key (defaults to slugified label). Sections with section-metadata 'Audience: <key>' (or elements with class audience-<key>) show only for the selected audience..

No variations.
