# callout

Custom **callout** block. Purpose: Call-to-action band pairing a short prompt with a button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One or more cells containing a short message (heading or paragraph) and one or more CTA links. Option 'photo': add a cell containing only an image; it becomes a full-bleed background behind a centred white panel holding the message and CTA..

## Supported variations

| --- | --- |
| Photo | `photo` |
