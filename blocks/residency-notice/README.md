# residency-notice

Custom **residency-notice** block. Purpose: Residency status panel explaining domestic vs international applicability.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per panel section (separated by rules). First section: a short title line (optional :icon: + e.g. 'Domestic student'), an optional one-link paragraph ('Change') shown inline, then explanatory text. Optional audience-keyed rows: cell 1 = audience key (domestic / international), cell 2 = content; only the section matching the audience-switcher selection is shown..

No variations.
