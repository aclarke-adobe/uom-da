# key-facts

Custom **key-facts** block. Purpose: Course key-facts panel (duration, mode, intake, fees) with primary CTAs.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Fact rows: cell 1 = label with optional :icon: (e.g. ':clock: Duration'), cell 2 = value text with optional link. Action rows: a single cell of CTA links (Save, How to apply, Enquire, Register for updates) shown in a right-hand column on desktop..
