# carousel

Custom **carousel** block. Purpose: Image gallery slider with captions.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Optional first row: single cell heading. Then one row per slide: cell 1 = image, optional cell 2 = caption text. Renders a one-at-a-time slider with previous/next buttons and a '1 / N' counter..

No variations.
