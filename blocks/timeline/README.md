# timeline

Custom **timeline** block. Purpose: Key dates / application process timeline.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per milestone: cell 1 = date (one line, or a small label line such as 'Monday' followed by the date line; leave empty to continue the previous date), cell 2 = description (optional heading plus text/links)..
