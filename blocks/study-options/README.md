# study-options

Custom **tabs** block. Purpose: Study-area course browser with tabbed, filterable course lists.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: single cell with the heading (e.g. 'Study options in Biomedical engineering') and optional intro text. Rows 2+: cell 1 = tab label (e.g. 'Degrees'), cell 2 = bulleted list of courses, each item a course link followed by optional '| Level | Study mode' text. Renders tabs with counts, Level/Study Mode filters derived from the items, a result summary and 'View more courses' after 5 results..
