# embed

Custom **embed** block. Purpose: Embedded third-party content such as a Google 360 tour or video.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Single cell: optional heading and intro text, optional placeholder image, then a link to the embeddable URL (Google Maps / Street View, YouTube, Vimeo or other iframe page) as the last link. The iframe lazy-loads (or loads on click when a placeholder image is provided)..

## Supported variations

No variations.
