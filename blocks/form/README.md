# form

Custom **form** block. Purpose: Authored forms and eligibility questionnaires.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Either a single link to a sheet (.json) or one row per field: Label | Type | Name | Options | Required. Types: fieldset (starts a grouped panel; Options = description), text, email, tel, number, date, textarea, select, radio, checkbox (Options = comma-separated choices), plaintext, submit. A row 'action | <url>' sets the POST endpoint..

No variations.
